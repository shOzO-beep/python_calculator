=Калькулятор на Python=
Мой учебный проект на Python - консольный калькулятор с поддержкой четырёх основных математических операций и обработкой ошибок.
Проект создан для практики программирования и закрепления знаний Python.

=Возможности=
+ = Сложение двух чисел 
- = Вычитание двух чисел 
* = Умножение двух чисел 
/ = Деление двух чисел 
Поддержка целых и дробных чисел 
Обработка неправильного ввода 
Защита от деления на ноль 
Повторное выполнение вычислений 
Возможность выйти из программы 

=Используемые технологии=
Python 
input() - ввод данных
if и elif - выбор математической операции
while - повторение программы 
from...import... - импорт из модуля 
try и except - обработка ошибок

=Как запустить=
1. Установить Python 3.15.0 , если он ещё не установлен 
2. Скачать или клонировать этот репозиторий
3. Открыть папку проекта в терминале
   Для этого нужно щёлкнуть левой кнопкой мыши по пути к файлу и написать cmd
4. В терминали запустить команду python calculator.py 
   Если команда python не работает, попробуйте py calculator.py

=Пример работы=
1:+ 
2:- 
3:/ 
4:*
0:Выход 

Выберите действие: 1
Число 1: 10 
Число 2: 5  
Результат: 15.0
